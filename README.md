# AlcarisItems

このプラグインは、カスタムアイテムの実装を簡単にするために開発されました。  
サーバー上のアイテムを自由にカスタマイズできる柔軟性と、より高度なアイテム作成を可能にする利便性を提供します。

## Dependencies

- [**AlcarisCore**](https://github.com/AlcarisMinecraftServer/AlcarisCore)
- [**AlcarisPlayer**](https://github.com/AlcarisMinecraftServer/AlcarisPlayer)

## Usage

1. **ダウンロード**
   - [Releases](https://github.com/AlcarisMinecraftServer/AlcarisCrafting/releases) ページから、最新版の `AlcarisItems.jar` をダウンロードしてください。

2. **配置**
   - ダウンロードした `AlcarisItems.jar` をサーバーの `plugins` フォルダーへ配置してください。

3. **サーバー起動**
   - サーバーを起動し、コンソールやゲーム内コマンドで `AlcarisItems` が正常に読み込まれているか確認してください。
